# Mobile (Flutter) scaffold

This folder contains a minimal Flutter app scaffold with a Home screen inspired by the Joymee Playstore screenshots.

Files added:
- lib/main.dart - main entry
- lib/screens/home_screen.dart - home UI (dark themed list + bottom navigation)
- pubspec.yaml - dependencies

Notes
- This is a UI mockup scaffold and does not include Play Store publishing files or real network integration.
- To continue: open the folder with Flutter SDK installed, run `flutter pub get` then `flutter run`.
- Implement API calls to the Laravel backend (backend API routes) and payment/SMS endpoints as next steps.
